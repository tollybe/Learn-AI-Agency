# Prompt: project debrief and teach-back

```text
Act as a mentor reviewing my completed project. Do not judge it by feature count.

Project brief:
[paste]

Artifact or README:
[paste/link]

Verification evidence:
[paste]

Decision notes:
[paste]

Please produce:
1. a plain-language summary of what the project proves I can do;
2. the correct evidence level for each relevant skill;
3. one important limitation or untested assumption;
4. three teach-back questions that reveal whether I understand the work;
5. one reusable pattern to extract;
6. one sensible next project that requires a little more independence.

Do not describe generated output alone as understanding. Be encouraging and evidence-based.
```
