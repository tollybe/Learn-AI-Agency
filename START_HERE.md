# Start here: from goal to first proof

Do not begin by choosing a 40-hour course. Begin with something you want to make possible.

## 1. Write your capability statement

Complete this sentence:

> I want to become able to **[do something observable]** for **[person or situation]**, so that **[useful outcome]**.

Weak: “I want to learn Python and AI.”

Stronger: “I want to use Python to turn a script and a set of images into a narrated multilingual video, so that I can prototype educational content without paying for enterprise cloud services.”

The stronger version gives your AI assistant something it can help you build and test.

## 2. Complete the learner profile

Open `learner/PROFILE.md`. Include:

- what you already know;
- what you have actually built;
- what you want to be able to do;
- time, money, language, accessibility, and technology constraints;
- what kind of help makes you more independent;
- what kind of help makes you passive.

Certificates belong under background. They are useful context, not proof that every related skill is already practical.

## 3. Run the capability diagnostic

Use `learner/SKILL_MAP.md` with an AI assistant. For each required skill, attach evidence or write “not demonstrated yet.” That phrase is neutral: it identifies the next experiment.

Your first project should be one step beyond what you can already demonstrate—not ten steps beyond it.

## 4. Set up your AI coach

Paste `prompts/AI_COACH.md` into your preferred AI assistant and replace the bracketed fields. If the assistant can read this repository, point it to `AGENTS.md` instead.

Ask it to help you create a first project brief. Do not ask for the full solution yet.

## 5. Use the attempt-first protocol

When you are stuck, bring evidence:

```text
Goal:
What I tried:
What happened:
The exact error or unexpected result:
My current theory:
What I want help deciding:
```

“It doesn't work” is the beginning of a diagnosis, not the end. Use `prompts/STUCK.md` to turn the situation into a better debugging conversation.

## 6. Finish with three proofs

A project is complete when you can show:

- **Artifact:** something another person can run, inspect, or use;
- **Reasoning:** the most important decision, test, and limitation;
- **Teach-back:** a clear explanation for the next learner.

Polish is optional. Evidence is not.

## Your first 45-minute session

1. 10 min — complete the top half of `learner/PROFILE.md`.
2. 10 min — write one capability statement.
3. 10 min — ask AI for three project ideas under your real constraints.
4. 10 min — choose the smallest project and define “done.”
5. 5 min — open an Agency Project issue and schedule the next build session.

Stop there. A useful next step beats an impressive plan that never becomes work.
